# 静读 · 本地阅读器

一个纯前端的本地 TXT 阅读器：不用安装、不联网、不上传任何内容。整本书读进浏览器本地存储，换电脑只换文件夹，不换账号。

> 仓库里**不含任何书籍内容**。书由你自己提供（TXT），导入后保存在浏览器里。

## 特点

| | |
| --- | --- |
| **两种翻页** | 整页翻动 / 平滑滚动，随时切换，选择会记住 |
| **回到原处** | 同时记录滚动位置和“屏幕顶端那一句”，刷新后回到同一行 |
| **自动阅读** | 按 `F8` 开始/暂停，速度可调，滚到章末自动进下一章 |
| **排版** | 背景 5 种、字体 3 种、字号 16–32、行距、字重 200–700、版心宽度可撑满 |
| **章节目录** | 自动识别“第 N 章”，缺章、重号会给提示 |
| **纯本地** | 只监听 `127.0.0.1`，零依赖，只用 Python 标准库 |

## 使用

### Windows

双击 `启动阅读器.bat` → 浏览器自动打开 → 把 TXT 拖进窗口。

### macOS / Linux

```sh
chmod +x start.sh
./start.sh
```

### 完全不用 Python

直接用浏览器打开 `静读阅读器.html` 也能读，只是浏览器不能自动读取同目录的书，把 TXT 拖进窗口即可。

首次打开是空书架，这就是正常状态：把 TXT 拖进去，书就进了浏览器本地存储，下次打开还在。

## 导入自己的书

- **直接拖**：把 TXT 拖进浏览器窗口，自动识别章节。
- **放进 `static/books/`**：启动后书架列表会显示该文件，GBK / UTF-8 都能认。
- **预生成书目**：本地放一个 `书的标题_静读书目.json`（字段 `title` / `author` / `charCount` / `chapters[]`），启动时会自动导入，不用每次手动拖。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` / `PageUp` `PageDown` | 上/下翻一页 |
| `Ctrl/Alt + ←` `Ctrl/Alt + →` | 上一章 / 下一章 |
| `F8` | 自动阅读 开始/暂停 |
| `T` | 换背景色 |
| `F` | 全屏 |
| `Home` | 回到本章开头 |
| `Esc` | 关闭面板 |

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `启动阅读器.bat` | Windows 双击启动 |
| `start.sh` | macOS / Linux 启动 |
| `启动器.py` | 找到 Python、同步文件、开浏览器、启服务 |
| `书架服务器.py` | 本地静态服务器，只用标准库 |
| `静读阅读器.html` | 阅读器本体（单文件，可直接打开） |
| `static/` | 运行时自动生成，被 `.gitignore` 忽略 |

## 说明

- 端口固定 `8765`。被占用时改 `启动器.py` 里的 `PORT`。
- 阅读进度存在浏览器 `localStorage` 里，**不会跟着文件夹走**。换电脑、换浏览器后需要重新定位。
- 阅读期间保持黑窗口开着，读完关掉即可。
